# Thymoleon Power Studio releases

Windows x64 downloads for Thymoleon Power Studio.

Open [Releases](https://github.com/drjanshair/thymoleon-power-studio-releases/releases) for the installer, portable ZIP, release notes and SHA-256 checksums.

For the portable ZIP, extract the full folder and run **Thymoleon Power Studio.exe** alongside the **binaries** folder. The packages contain the desktop app and its backend. Simulator licenses and model runtime dependencies are supplied separately.
